# Attribution

## Chant text

The Pali text of the Chinabunchorn Chant (พระคาถาชินบัญชร) is traditional material in the public
domain. This project uses the Thai-script recension reproduced on Thai Wikisource:

- Source: <https://th.wikisource.org/wiki/พระคาถาชินบัญชร>
- Retrieved: 4 November 2026
- Page licence: CC BY-SA 4.0. The underlying chant is public domain; the transcription is attributed
  here with the same licence.

The Roman transliteration is a pronunciation guide prepared for this project, not a critical edition.
The Thai and English glosses are original plain-language summaries written for this project and are
released under CC BY-SA 4.0 so they travel with the source text.

## Typefaces

No webfonts are downloaded or redistributed. The design uses the operating system's Thai and serif
fonts (`Sarabun`, `Noto Sans Thai`, `Thonburi`, `Iowan Old Style`, Georgia) with system fallbacks.

## What is not included

No audio files, video files, images of the Buddha, temple logos, or third-party brand assets are
bundled. Screenshots in `docs/` were captured from this application. The mandala, particles and glow
textures are generated procedurally at runtime.

## Redistribution checklist

If you fork this project:

1. Keep this file and `LICENSE`.
2. Keep the YouTube credit and do not re-host the video.
3. If you change the chant text, verify it against an authoritative recension and record the edition
   and retrieval date.
4. If you translate the glosses into another language, state who wrote them and under what licence.
